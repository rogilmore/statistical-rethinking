Components of the model

See (2020, pp. 32–35).

\[ Pr(W,L|p)=\frac{(W+L)!}{W!L!}p^W(1-p)^L \tag{1}\]

The probability of \(W\) and \(L\), conditional on \(p\) is defined by the formula in Equation 1.

The dbinom() function computes this binomial probability. To compute the probability of observing \(x=6\) \(W\)s in 9 globe tosses with \(p=4\), we proceed as indicated below:

```{r}
#| code-fold: false
dbinom(x = 6, size = 9, prob = 0.5, log = FALSE)
```
[1] 0.1640625

So, to compute the binomial probabilities for observing all \(n+1\) possible cases, we proceed as follows:

```{r}
#| code-fold: false

# Generate the data
n_W <- 0:9
p_n <- purrr::map(n_W, dbinom, size = 9, prob = 0.5, log = FALSE) |>
  purrr::list_c()

like_1 <- data.frame(n_obs = n_W, p_n = p_n)

# Plot the data
like_1 |>
  ggplot() +
  geom_point(aes(x = n_obs, y = p_n)) +
  theme_classic()
```

est_p_water <- function(obs, p = 0.5, n_pts = 20) {
    assertthat::assert_that(is.character(obs))
    assertthat::is.number(p)
    assertthat::assert_that(p > 0 & p <= 1)
    assertthat::is.number(n_pts)
    assertthat::assert_that(n_pts > 0)

    p.grid <- seq(from = 0, to = 1, length.out = n_pts)
    prior <- rep(p, n_pts)
    n_W <- sum(obs == "W")
    likelihood <- dbinom(n_W, size = length(obs), prob = p.grid)
    posterior.unstd <- likelihood * prior
    posterior <- posterior.unstd / sum(posterior.unstd)
    m_comment <- paste0(
        n_W,
        " water observations out of ",
        length(obs),
        " | ",
        n_pts,
        " points"
    )
    plot(
        p.grid,
        posterior,
        type = "b",
        xlab = "probability of water",
        ylab = "posterior probability"
    )
    mtext(m_comment)
}

PM3. Two globes, Earth with p(Water)=0.70 and Mars with p(Water)=0.

We want to compute \(p(Earth|land)\).

\(p(Earth|land)=\frac{p(land|Earth)p(Earth)}{p(land)}\)

\(p(land|Earth)=0.30\) \(p(land|Mars)=1.0\) \(p(Earth)=0.5\) \(p(land)=0.5*p(land|Earth)+0.5*p(land|Mars)\)

Code 
p_land_Earth <- 0.30
p_land_Mars <- 1
p_Earth <- 0.5
p_land <- p_Earth * (p_land_Earth) + (1 - p_Earth) * p_land_Mars

p_Earth_land <- (p_land_Earth * p_Earth) / p_land
p_Earth_land

2M4. Card deck with three cards.

\(c_{bb}\rightarrow{b,b}\) \(c_{bw}\rightarrow{b,w}\) \(c_{ww}\rightarrow{w,w}\)

There are two events. One involves the choice of card, the other involves the choice of side. So, the space of possible outcomes when the observer chooses one card is as follows:

\(b,b,b,w,w,w\)

\(c_{bb}\) could produce the observed data (black side up) in 2 ways. \(c_{bw}\) could produce the observed data in one way. \(c_{ww}\) could not produce the observed data, so there are zero ways.

So, there are three ways the observed data could be produced. In two of the ways, the other side is black. Thus, \(p(other-side-black|observed)=2/3\)

2H1. Pandas.

\(p(twin|A)=.1\) \(p(twin|B)=.2\)

We observe a panda who gives birth to twins, what is the probability that the next birth will also be twins? Species is unknown.

Species unknown and likely sampled in equal proportions means that \(p(A)=p(B)=0.5\)

Species A could generate the observed first birth in 1/10 ways. Species B could generate the observed first birth in 2/10 ways. We want the probability of observing two consecutive twin births, \(p(twin*twin)\).

\(p(twin*twin)=p(twin*twin|A)p(A)+p(twin*twin|B)p(B)\) \(p(twin*twin)=p(twin|A)*p(twin|A)*p(A)+p(twin|B)p(twin|B)*p(B)\)

Code 
p_twin_A <- 0.1
p_twin_B <- 0.2
p_A <- 0.5

p_twin_twin <- p_twin_A * p_twin_A * p_A + p_twin_B * p_twin_B * (1 - p_A)
p_twin_twin
[1] 0.025

So, the probability that the next birth will be a twin, given that the first was a twin, $p(twin,twin)=$0.025.

2H2. More pandas

What is the probability that the species is A, given that the first birth is a pair of twins? In other words, what is \(p(A|twin)\)?

\(p(A|twin)=\frac{p(twin|A)*p(A)}{p(twin)}\)

\(p(twin)=p(twin|A)*p(A)+p(twin|B)*p(B)\)

Code 
p_twin <- p_twin_A * p_A + p_twin_B * (1 - p_A)
Code 
p_A_twin <- (p_twin_A * p_A) / p_twin
p_A_twin
[1] 0.3333333

So, \(p(A|twin)\)=0.3333333.

est_p_water <- function(obs, p = 0.5, n_pts = 20) {
    assertthat::assert_that(is.character(obs))
    assertthat::is.number(p)
    assertthat::assert_that(p > 0 & p <= 1)

    n_W <- sum(obs == "W")

        " points"
    )

        p.grid,
        posterior,
        type = "b",
        xlab = "probability of water",
        ylab = "posterior probability"
    )

}

### 2M4. Card deck with three cards.

$c_{bb}\rightarrow{b,b}$
$c_{bw}\rightarrow{b,w}$
$c_{ww}\rightarrow{w,w}$

There are two events. One involves the choice of card, the other involves the choice of side.
So, the space of possible outcomes when the observer chooses one card is as follows:

$b,b,b,w,w,w$

$c_{bb}$ could produce the observed data (black side up) in 2 ways.
$c_{bw}$ could produce the observed data in one way.
$c_{ww}$ could not produce the observed data, so there are zero ways.

So, there are three ways the observed data could be produced. In two of the ways, the other side is black.
Thus, $p(other-side-black|observed)=2/3$

### 2H1. Pandas.

$p(twin|A)=.1$
$p(twin|B)=.2$

We observe a panda who gives birth to twins, what is the probability that the next birth will also be twins?
Species is unknown.

Species unknown and likely sampled in equal proportions means that $p(A)=p(B)=0.5$

Species A could generate the observed first birth in 1/10 ways.
Species B could generate the observed first birth in 2/10 ways.
We want the probability of observing two consecutive twin births, $p(twin*twin)$.

$p(twin*twin)=p(twin*twin|A)p(A)+p(twin*twin|B)p(B)$
$p(twin*twin)=p(twin|A)*p(twin|A)*p(A)+p(twin|B)p(twin|B)*p(B)$

```{r}
p_twin_A <- 0.1
p_twin_B <- 0.2
p_A <- 0.5

p_twin_twin <- p_twin_A * p_twin_A * p_A + p_twin_B * p_twin_B * (1 - p_A)
p_twin_twin
```

So, the probability that the next birth will be a twin, given that the first was a twin, $p(twin,twin)=$`{r} p_twin_twin`.

### 2H2. More pandas

In other words, what is $p(A|twin)$?

$p(twin)=p(twin|A)*p(A)+p(twin|B)*p(B)$

p_twin <- p_twin_A * p_A + p_twin_B * (1 - p_A)
