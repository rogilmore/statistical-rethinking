To replicate Figure 4.2.

```{r}
rw <- function(steps = 1, n = 50) {
  df <- data.frame(trajectory = 1:n, step = rep(0, n), pos = rep(0, n))
  this_df <- df
  for (i in 1:steps) {
    new_pos <- this_df$pos + runif(n, -1, 1)
    this_df <- data.frame(trajectory = 1:n, step = rep(i, n), pos = new_pos)
    df <- rbind(df, this_df)
  }
  df
}
```

```{r}
rw16 <- rw(16)
```
