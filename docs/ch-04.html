4.1.4

Merely as an exercise to practice LaTex, here is the equation on p. 76:

\[p(y|\mu,\sigma)=\frac{1}{\sqrt{2\pi\sigma^2}}exp(-\frac{(y-\mu)^2}{2\sigma^2})\]

Let’s also try the \(\tau\) version:

\[p(y|\mu,\tau)=\sqrt{\frac{\tau}{2\pi}}exp(-\frac{1}{2}\tau(y-\mu)^2)\]

4.2

For my own amusement I decided to create a function around R code 4.6.

Code 
earth_water <- function(w = 6, n = 9, l = 100) {
  assertthat::is.number(w)
  assertthat::is.number(n)
  assertthat::is.number(l)
  assertthat::assert_that(w >= 0)
  assertthat::assert_that(n > 0)
  assertthat::assert_that(n >= w)
  assertthat::assert_that(l > 0)

  p_grid <- seq(from = 0, to = 1, length.out = l)
  posterior <- dbinom(w, n, p_grid) * dunif(p_grid, 0, 1)

  data.frame(p = p_grid, post = posterior / sum(posterior))
}
